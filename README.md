One funny passive-aggressive note a smart fridge leaves for its owner: dry, petty, and specific, about the leftovers the owner keeps promising to eat. The program writes the single line to `entry.txt` (UTF-8, 90 characters, no trailing newline).

> The leftovers you swore you would eat have started a family. I named the eldest after you.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fridge-note-out python3 main.py
```
